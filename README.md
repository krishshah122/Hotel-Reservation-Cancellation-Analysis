# 🏨 Hotel Booking Cancellation Analysis

An end-to-end Data Analytics project focused on analyzing hotel booking behavior and identifying patterns behind booking cancellations using Python, SQL, and Power BI.

---

# 📌 Project Overview

This project analyzes hotel booking data to uncover insights related to:
- Booking cancellations
- Customer behavior
- Seasonal trends
- Revenue impact
- Market segments
- Booking patterns

The goal is to help hotels reduce cancellations and improve business decisions using data-driven insights.

---

# 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- PostgreSQL / SQL
- Power BI
- Jupyter Notebook

---

# 📂 Dataset Information

The dataset contains hotel booking records with features such as:

- Hotel Type
- Lead Time
- Arrival Date
- Market Segment
- Customer Type
- ADR (Average Daily Rate)
- Booking Status
- Number of Guests
- Meal Type
- Special Requests
- Cancellation Status

# ⚙️ Data Preprocessing

Performed multiple preprocessing and cleaning steps:

- Removed duplicate records
- Handled missing values
- Converted data types
- Performed feature engineering
- Standardized column names
- Created derived analytical features

# 📊 Exploratory Data Analysis

Conducted detailed EDA to identify:

# 🧠 SQL Business Analysis

Performed SQL analysis to answer business questions such as:

- Which hotel type has the highest cancellation rate?
- Which customer segment generates maximum revenue?
- What months experience the most cancellations?
- Does lead time affect booking cancellations?
- Which countries contribute the most bookings?
- What booking channels perform best?

# 📈 Power BI Dashboard

Built an interactive dashboard including:

- Cancellation KPIs
- Revenue analysis
- Booking trends
- Customer segmentation
- Hotel performance metrics
- Seasonal insights

---

# 🔑 Key Insights

- City hotels showed higher cancellation rates
- Longer lead times increased cancellation probability
- Online travel agents generated the highest bookings
- Certain months experienced peak cancellations
- Repeated guests had lower cancellation rates
